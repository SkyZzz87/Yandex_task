# Задача 2

Engagement rate показывает долю пользователей, которые взаимодействовали с контентом, среди всех пользователей, которые его просмотрели.

**Формула:**

Engagement Rate = (количество уникальных пользователей с взаимодействием / количество уникальных пользователей с просмотром) × 100%.

Если просмотров нет, показатель не рассчитывается, чтобы избежать деления на ноль.
Повторные взаимодействия одного пользователя считаются как одно взаимодействие.
Пользователи с пропущенным идентификатором не должны учитываться в расчёте.
Ботов и технические аккаунты нужно исключать, если они присутствуют в данных.

**Термин для глоссария — уникальный пользователь:** пользователь, который учитывается в расчёте только один раз независимо от количества его действий.
